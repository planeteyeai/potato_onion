POTATO & ONION COMMODITY INTELLIGENCE HTML DASHBOARD

1. Extract the ZIP.
2. Open index.html in Chrome/Edge/Firefox.
3. No Python or server is required for this prototype.

The dashboard includes:
- Command Center
- Market/Mandi Intelligence
- Procurement Finder
- Finance Screening
- Storage & Logistics
- Risk & Scenario Forecast
- Report Center with CSV downloads

The displayed figures are illustrative prototype data. For production, connect the dashboard JavaScript to authenticated APIs/backend services and replace the illustrative data with verified feeds.
